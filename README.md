# Dashify-Dashboard-
Додавання, видалення та перетягування віджетів (Drag-and-Drop) на сітці (Grid layout).  Різні типи віджетів: графіки (Recharts / Chart.js), списки завдань, міні-календар, курси валют, погода.  Фільтрація даних за датами та категоріями.  Темна / світла тема та збереження конфігурації панелі у localStorage або базу даних.
